# 2026-07-02 — Session 1: Full audit, repair, and optimization

Full-system audit of every pipeline, the frontend, workflows, and data layer,
followed by repairs. Findings were verified against live APIs and CI logs
before fixing. ~40 defects addressed across 20 files.

## Headline repairs

1. **Bill pipeline crash (52 of last 60 CI runs failed)** — `run_fetch_bills.py`
   referenced `raw_text` on the cached-bill path where it was never assigned
   (`UnboundLocalError`). Any warm cache crashed the run. Fixed with an
   explicit `has_text` flag.
2. **House trades scraper never worked** — it skipped all `.pdf` links and
   parsed an HTML table the Clerk site doesn't serve; zero House trades were
   ever collected. Rebuilt (`fetch_house_trades.py`): yearly `{year}FD.zip`
   index from disclosures-clerk.house.gov → PTR PDFs via pdfplumber →
   attribution by state/district (verified 269/269 filings matched, real
   trades extracted).
3. **Donor pipeline never worked** — FEC Schedule A rejects `candidate_id`
   (HTTP 400, verified live); every run silently stored nothing. Fixed
   (`fetch_donors.py`): candidate → authorized committees → Schedule A by
   `committee_id` + `is_individual`. Also derives `top_donor_industries`
   from employer/occupation keywords, which activates…
4. **Donor-vote alignment signal (20% of the anomaly score) was dead** —
   `donor_alignment_score` was 0.0 in all 542 detail files because its input
   (`top_donor_industries`) was never produced and keyword matching used
   substrings ("gun" matched "begun"). Fixed end to end (word-boundary
   matching, correct 0–100 scale, ALEC double-count removed).
5. **Travel scraper structurally broken** — the old PDF-table approach could
   never attribute trips (and travel disclosure PDFs turn out to be scanned
   images). Rebuilt (`fetch_travel_pdf.py`) on the Clerk's consolidated Gift
   Travel Filings search (verified live: 6,022 filings, 1,051 trips matched,
   0 ambiguous).
6. **Supabase project is dead** — `ufrsumaylshtikwociwp.supabase.co` is
   NXDOMAIN. Every frontend Supabase query has been failing; the JSON
   fallback was carrying the site. Frontend now treats same-origin JSON as
   primary and Supabase as fallback. (Decide: revive Supabase with a new
   project + URL/key, or strip the integration.)

## Data-integrity hardening (all pipelines)

- Atomic writes everywhere (temp file + `os.replace`) — a crash mid-write
  can no longer truncate `members.json`, detail files, or the bills cache.
- Guarded loads — a corrupt existing JSON file now ABORTS the run instead of
  being treated as `{}` and overwritten (this silently wiped other
  pipelines' fields before).
- `fetch.py`: per-page retry with backoff on Congress.gov timeouts (the
  cause of the 2026-07-02 CI failure); a partial pagination now aborts
  instead of silently dropping members missing from the fetched pages.
- `latest_trade_date` was computed with string `max()` over `MM/DD/YYYY`
  dates (month-first ordering — Booker showed "08/08/2014"). All date
  comparisons now parse first; new trade dates stored as ISO `YYYY-MM-DD`.

## Scoring correctness (`fetch_finance.py`)

- FEC `state` param sent full state names (silently ignored) → 2-letter
  codes + exact-state result matching.
- Hardcoded `cycle: 2026` missed ~2/3 of the Senate → picks the most recent
  cycle with receipts.
- `individual_contributions` was PATCHed to Supabase as 0 for all members
  every run → finance figures only sent when actually present.
- EDGAR failures returned 0 (indistinguishable from a real zero, clobbering
  prior counts) → `None` + keep last-known value.
- FEC/EDGAR outages now fall back to last-known detail values instead of
  collapsing the wealth-gap signal to 0.
- Trade/travel recency windows compared mixed date formats lexicographically
  → normalized via `parse_date_any`.
- `stats.json` hardcoded 538 members; tenure math hardcoded year 2026 →
  dynamic.

## Bill similarity engine

- Congress.gov "Formatted Text" is HTML and was never stripped — markup
  tokens shared by every bill inflated all similarity scores. Now stripped;
  HTML-polluted cache entries invalidated gradually (300/run).
- Bigrams were generated twice (manually + vectorizer `ngram_range`) →
  single source.
- ALEC matching now skipped on a cold corpus (<50 bills) where the
  vocabulary would be dominated by the 15 ALEC templates.
- Raw best ALEC cosine now stored (`alec_best_similarity`) even below the
  0.80 threshold, so the graduated 0.35/0.5/0.65 score buckets in
  `fetch_finance.py` are reachable (they were dead code).
- LegiScan budget under-counted real API calls ~3× → honest accounting.
- ALEC vectors computed once per run instead of per bill; throttling moved
  into the shared API getters (several `_sleep()` calls sat after `return`).
- Senate eFD: pagination no longer stops on all-paper pages; ambiguous
  same-surname filings are skipped instead of blindly attributed to the
  first candidate; tickers/assets stored as plain text.
- Votes: `vote_id` used salted `hash()` (different every process — daily
  duplicate rows in Supabase) → md5; HTTP failures now labeled
  `fetch_failed` instead of `no_recent_votes`.

## Frontend (`index.html`, `vercel.json`)

- XSS: added `esc()`/`safeUrl()`/`stripTags()` and applied to every dynamic
  interpolation (names, bill titles, PTR asset text, URLs…). Legacy
  HTML-anchor tickers now render as plain text.
- Stale-response race in `openProfile` fixed with a request token; added an
  in-memory detail cache.
- Data loading flipped: same-origin JSON primary, Supabase fallback.
- `vercel.json`: `no-store`-everything replaced with `no-cache` for pages
  and `public, max-age=300, s-maxage=3600, stale-while-revalidate=86400`
  for `/data/*` (was re-downloading 273KB `members.json` on every view).
- Back-button trap removed (popstate no longer re-pushes state forever).
- Mobile: bottom-nav Bills/Donors/Trades/Compare no longer dead without an
  open profile (toast + members view); anomaly score no longer hidden on
  phones; grid columns monotonic across breakpoints.
- Score 0 no longer conflated with "no data"; hardcoded 538 counts now live;
  coverage panel counts real fields; CSV export quoted + formula-injection
  safe; duplicate chart function removed; misleading net-worth caption fixed.
- Browser smoke test passed (member list, profile, stocks tab, charts).
