## The finance failure ("dormant path awakens")

The EDGAR fix produced `needs_review` CIK candidates for the first time ever,
so `fetch_finance.py` wrote `data/unresolved_cik_candidates.json` — a file the
workflow's `git add` list never included. The stray unstaged file made
`git pull --rebase` refuse and the run's entire committed output was lost with
the runner (run 30818652004), despite the data work having succeeded.

Fix (`7ca784fd1`): stage the CIK review file explicitly in
`fetch-finance.yml`, and add `--autostash` to EVERY pipeline's pull so a
future new output file can never kill a push again. All 11 workflow files
touched.
