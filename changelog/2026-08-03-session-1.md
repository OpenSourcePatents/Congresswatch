# 2026-08-03 — Session 1: OSP design-system reskin

## Summary

Full visual + information-architecture rewrite of the frontend to the approved
OpenSourcePatents (OSP) portal design system. Appearance and layout only — the
data contract (`data/members.json`, `data/details/{bioguideId}.json`), every
computation, and all Python pipelines are untouched.

## Files created

- **`osp-logo.jpg`** — OSP logo copied from the `osp-portal` repo's `public/`
  directory (referenced locally, not hotlinked).
- **`changelog/2026-08-03-session-1.md`** — this file.

## Files modified

- **`index.html`** — complete reskin:
  - **Type system**: Bebas Neue + IBM Plex Sans removed; now Oxanium (headings,
    labels, buttons, chips, stat numbers), IBM Plex Mono (dates, IDs, amounts,
    source notes, disclaimers), Barlow (prose).
  - **Color tokens**: full `:root` custom-property palette from the OSP portal
    (red/white/blue accents, glass backgrounds, layered borders, radii,
    letter-spacing scale). All legacy hex values (`#e8ff00`, `#ff3c00`,
    `#00d4ff`, `#0a0a0a`, …) removed. New score color scale:
    ≥80 critical `#ff3b4e`, ≥60 high `#ff7a4e`, ≥40 elevated `#f3c25a`,
    <40 typical `#9fe7c8`, null pending `#5d7180`.
  - **Ambient backdrop**: fixed grid + vignette layer and dual animated
    scanlines (`grid-scan` / `scan-color` keyframes) behind all content, with a
    `prefers-reduced-motion` kill switch.
  - **Chrome**: new OSP global nav (spinning logo, portal links, `API →`
    button, hamburger below 900px), restyled amber notice strip (same copy),
    new product bar (two-tone CONGRESSWATCH wordmark, tagline, live-data
    pulse), and the OSP portal footer (brand column, three link columns,
    bottom bar).
  - **IA**: 280px sidebar, two-column `.app` grid, mobile bottom nav and
    `mobileNav()` deleted. Single centered 1180px column. Sidebar content
    relocated: filters/search/sort into one sticky control bar with labeled
    chip groups; Data Coverage and Data Sources into two glass panels below
    the grid (coverage now has progress bars; sources use live/coming dots
    instead of `✓`/`◌`).
  - **Member grid**: full-bleed photo tiles replaced with glass cards
    (party stripe, 52×64 photo thumb with CSS background-image +
    initials fallback — no `onerror` handlers, round score badge, tag chips).
    Paginated: 60 cards + "Load N more" button instead of rendering all 537.
  - **Profile**: new header (back button + `MEMBER VAULT / {bioguideId}`
    breadcrumb, glass hero with pills, label/value pairs, glowing score block
    with band label), restyled tabs (`Bills & votes` label), and all eight
    panels rebuilt on shared slot builders (stat cells → alerts → tables →
    charts → link buttons → empty message).
  - **NEW — Anomaly score breakdown** (Overview): the six weighted signals
    from `detail.score_components` are now rendered, with track width encoding
    each signal's max weight and fill encoding the member's value
    (green 0 / amber / red-bright ≥60% of max; `pending` when absent).
  - **Panel content upgrades**: stock tickers now link to each trade's
    `ptr_link`; travel sponsors link to `source_doc`; Patterns lists
    `top_donor_industries`; Donors table gains Employer / Occupation / Date
    columns; Overview insider-signals note reads `SEC EDGAR Form 4`.
  - **Charts**: same canvas code, new palette (blue salary line, red dashed
    cumulative line, blue/red bar charts, blue donor-network edges with red
    member node), height 160→170, left padding 56, and a
    `drawWhenSized()` guard that retries until the canvas has real width.
  - **Behavior preserved**: `computeScore`, `computeCareerEarnings`,
    `hasRealData`, `mapMember`, `buildFlags`, `applyFilters`, `fillCompare`,
    CSV/JSON export, share, history/popstate single-entry handling, Escape to
    close, `profileToken` stale-fetch guard, `detailCache`,
    `esc`/`safeUrl`/`stripTags`, `wireFilters`/`wireSearch`/
    `syncFilterButtons` (now wired to the control bar).
