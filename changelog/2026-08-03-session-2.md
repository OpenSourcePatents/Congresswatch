# 2026-08-03 — Session 2: fix member photos (wrong thumbnail host) + bioguide fallback

## Summary

Session 1's optimization pointed `photoUrl()` at
`https://theunitedstates.io/images/congress/225x275/{bioguideId}.jpg`. That host
does not serve decodable images for these paths (curl shows HTTP 410 with an
empty body; some paths answer 200 `text/html`) — and since CSS
`background-image` failures are silent, every member photo site-wide fell back
to initials with no console errors.

Fixes in `index.html` (single-file frontend, no new dependencies):

1. **Host fix** — `photoUrl()` and the `<head>` `preconnect` now use
   `https://unitedstates.github.io/images/congress/225x275/{id}.jpg`, the GitHub
   Pages origin of the same unitedstates/images project, which serves real JPEGs
   (HTTP 200, `image/jpeg`, `ff d8` magic bytes, ~15–70KB).
2. **Bioguide fallback for the newest members** — the unitedstates/images
   automation lags new arrivals: of the 20 newest members by `term_start`, 7
   were 404 on the CDN (all six 2026-01-01 arrivals + one 2025 member). New
   `setPhoto(el, primary, fallback)` probes the thumb with `new Image()` and
   only paints the CSS background on success; on 404 it retries with the
   member's full-size `photo_url` (bioguide.congress.gov portrait). The probe
   and the background paint share the HTTP cache, so each card still fetches
   only ONE decodable image; the fallback costs one tiny 404 response first.
   - `mapMember` now also emits `photoFb` (bioguide URL, empty when the primary
     already is the bioguide URL); card thumbs carry it as `data-photo-fb`.
   - Wired through all three consumers: the `photoObserver` lazy-load callback,
     the no-IntersectionObserver direct path, and the profile header
     (`pf-photo`); `photoFb` is preserved across the vault deep-merge.
3. Lazy loading (IntersectionObserver, 300px rootMargin) from session 1 is
   retained unchanged.

Photo coverage after the fix: 535/537 members. The two exceptions (G000608,
A000383) have no published portrait anywhere — bioguide 404s too — so initials
is the correct display for them.
