# SEC partial-outage preservation

Finance run 267 recorded SEC alias HTTP 500 failures. The previous resolver
interpreted incomplete alias searches as unresolved/needs_review, then zeroed
stored counts and cleared CIKs. Verified count/CIK losses in five members' main
records: Gregory Murphy, James Moylan, Katherine Clark, Young Kim, Todd Young.
This is an ingestion-state bug, not evidence that any prior automatic identity
match or alleged activity was correct.

## Changed files
- `fetch_finance.py`: distinguish partial alias/schema failure from verified empty
  results; preserve prior CIK/count on failed refresh, including failed counts for
  a newly resolved CIK; add checked/successful-update and stale/unavailable status;
  make partial SEC failure visible at job completion.
- `.github/workflows/fetch-finance.yml`: save valid/retained data after an incomplete
  run, then leave the workflow failed rather than falsely green.
- `index.html`: show stale SEC warning; suppress fresh-activity flags for failed
  refreshes. Existing CSS/layout unchanged.
- This changelog.

## Validation and limits
Python compilation, inline JavaScript syntax, whitespace checks and full-roster
read-only audit passed. A live read-only Murphy lookup now succeeds and returns
three filings at the historical automatically selected CIK. This checks the
success flow, not independent identity attribution. Failure handling was reviewed
against actual run267 errors; no synthetic fixture/suite was added. No source
JSON, production branch or deployment was changed in this patch. Already damaged
main data is not silently restored or claimed independently verified.
