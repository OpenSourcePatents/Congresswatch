# 2026-08-03 — Session 7

Fixes GitHub issue #17 (Data Review Request: Christopher Murphy — profile showed
1000% missed votes, inflating his anomaly score).

## Root cause

Two independent defects stacked on the same signal:

1. **Unit doubling in the frontend.** `recompute_scores.py:87` already stores
   `missed_votes_pct` as a percentage (0–100). `index.html` multiplied it by 100
   again, so Murphy's real 10.0% rendered as "1000%".
2. **A scorer that saturated far too early.** The attendance component used
   `min(5, round((missed/len(votes)) * 50))`, which awards the full 5-point
   penalty at just 10% missed. Combined with a 20-vote sample window (every
   ratio a multiple of 5%), nearly every member with any absence at all was
   pinned at the maximum penalty.

## Modified

- `index.html`
  - Line ~1135: removed the erroneous `*100` on `missed_votes_pct`; the value is
    already a percentage.
  - Replaced the truthiness guard with `!= null` so a legitimate 0.0% renders as
    "0.0%" instead of the row vanishing.
- `fetch_votes.py`
  - New `VOTE_WINDOW = 100` constant; GovTrack `vote_voter` is now fetched at
    `limit=100` instead of `limit=20`. Verified against the live API: it returns
    100 objects with `meta.limit: 100`. Existing 429 backoff untouched.
  - Module docstring updated to match.
- `fetch_finance.py`
  - New constants `MIN_VOTES_FOR_ATTENDANCE = 20` and
    `ATTENDANCE_SATURATION_PCT = 25`.
  - `compute_score_components()` attendance signal: samples under 20 votes now
    score 0 (insufficient sample) instead of being scored on noise; the penalty
    is linear in missed-vote percentage and saturates at 25% missed rather than
    10%. `recompute_scores.py` imports this same function, so both scorers stay
    consistent by construction.
- `README.md` — documented the attendance methodology: the 100-vote window, the
  25% saturation point, the under-20-vote guard, and the fact that the profile's
  >15% absence flag is a warning tier deliberately below the scoring saturation
  point.

## Regenerated
