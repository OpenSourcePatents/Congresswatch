# 2026-08-03 — Session 8

Follow-up to session 7 / issue #17: exempt non-voting delegates from the
attendance signal. Session 7 fixed the attendance *curve*; this fixes *who the
signal applies to at all*.

## Problem

Five House delegates and Puerto Rico's Resident Commissioner cannot vote on
final passage, but were being scored on "missed" votes they are structurally
ineligible to cast. Two of them (P000610, R000600) were carrying the maximum
5-point attendance penalty as a result.

The member schema has no role/type field, so classification is by exact
state + chamber match. Upstream vote data cannot be used as the signal: all six
delegates currently have 20 stored vote records, but four read 0.0% missed and
two read 100% — so exclusion is identity-based, never data-based.

## Modified

- `fetch_finance.py`
  - New `NON_VOTING_STATES` frozenset (the six territories/districts) and
    `is_non_voting_delegate(member)` helper.
  - `compute_score_components()` attendance signal now short-circuits to 0 for
    delegates before any vote-ratio math. `recompute_scores.py` imports this
    same function, so both scorers remain consistent by construction.
- `recompute_scores.py`
  - Publishes `non_voting_delegate` (bool) to both `members.json` and each
    detail file.
  - Writes `missed_votes_pct: null` for delegates rather than a percentage
    derived from untrustworthy upstream data.
- `index.html`
  - New `NON_VOTING_STATES` Set + `isNonVotingDelegate()`, mirroring the Python
    side. Prefers the published `non_voting_delegate` flag, falling back to
    state + chamber so the UI is correct against detail files written before the
    flag existed.
  - Profile MISSED VOTES row renders "N/A — non-voting delegate" for delegates.
    This short-circuits ahead of the percentage branch, so BOTH the 0.0% and
    100% upstream shapes render as N/A.
  - Both other missed-vote render paths suppressed for delegates: the
    HIGH MISSED VOTE RATE warning flag and the corresponding pattern entry.
- `README.md` — documented the exemption, the six seats, and the exact-match
  requirement.
